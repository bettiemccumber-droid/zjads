Zhijun Ads Manager

Zhijun Ads Manager is a Google Ads management tool for viewing and adjusting campaigns, keywords, and budgets. After you grant access, you can review campaign performance, change budgets and bids, and manage keywords in this tool. The adwords scope is used only to read and change Google Ads accounts you explicitly authorize. It is not used for any undisclosed purpose, and it is not used to resell data, analyze industry data, or train models. No sign-in is required to read this page. The tool does not generate AI content, including non-consensual intimate imagery (NCII), and it will not use the Google Ads API to create such imagery. Zhijun Ads Manager complies with the Google API Services User Data Policy.
