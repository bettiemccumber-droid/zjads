Zhijun Ads Manager

Zhijun Ads Manager 是一个 Google Ads 广告管理工具，用于查看和调整广告系列、关键字和预算。用户授权后，可在本工具中查看广告系列表现、调整预算与出价、管理关键字。我们请求 adwords 权限仅用于读取和修改用户明确授权的广告账户数据，不会用于任何未披露的用途，也不会用于转售、分析行业数据或训练模型。本页无需登录即可阅读。Zhijun Ads Manager 遵守 Google API Services User Data Policy。
