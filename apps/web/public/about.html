Zhijun Ads Manager

Zhijun Ads Manager is a Google Ads management application operated by Wenzhou Lucheng District Zhijun Ecommerce Firm. Its purpose is to let an authorized user manage the Google Ads accounts that user explicitly connects: review campaign performance, create and update search campaigns, and change keywords, budgets, and bids. This page is public. No sign-in is required to read it.

What Zhijun Ads Manager does

Authorized users review clicks, impressions, conversions, and spend; create and update campaigns, ad groups, and ads; manage keywords and match types; and change budgets and bids.

Why it requests Google Ads access

Zhijun Ads Manager requests one Google API scope and calls the Google Ads API with it: https://www.googleapis.com/auth/adwords. The scope is used only to read and change Google Ads accounts you explicitly authorize. It reads account and manager-account identifiers, campaigns, ad groups, ads, keywords, budgets, bids, spend, clicks, impressions, conversions, and ad assets such as sitelinks and callouts. That data is used only inside Zhijun Ads Manager for advertising management, viewing, and adjustment. It is not sold, not used to target consumers, not used to train models, not shared for any other company's use, and not used for any undisclosed purpose.

Google API Services User Data Policy

Zhijun Ads Manager complies with the Google API Services User Data Policy, including the Limited Use requirements. The application does not generate AI content, including non-consensual intimate imagery (NCII), and it will not use the Google Ads API to create such imagery.
