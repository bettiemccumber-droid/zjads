Zhijun Ads Manager

Zhijun Ads Manager is an internal Google Ads management tool used only to manage our own Google Ads accounts. This public homepage is https://www.zjads.top/. No sign-in is required to read this page.

The purpose of this application is to let authorized personnel of Wenzhou Lucheng District Zhijun E-commerce Firm (温州市鹿城区志君电子商务商行) review cost, clicks, impressions, and conversions, and manage the firm’s own campaigns. We do not sell Google Ads data. The tool does not generate AI content, including non-consensual intimate imagery (NCII), and it will not use the Google Ads API or any Google API to create such imagery.
