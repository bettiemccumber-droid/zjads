What Zhijun Ads Manager does

After you grant access, Zhijun Ads Manager is used to view and change your Google Ads campaigns in this application instead of only in the Google Ads interface. Authorized users can:

  • Review campaign performance, including clicks, impressions, conversions, and spend
  • Create and update campaigns, ad groups, and ads
  • Manage keywords and match types
  • Change budgets and bids

Why it requests Google Ads access

Zhijun Ads Manager requests one Google API scope, https://www.googleapis.com/auth/adwords, and calls the Google Ads API with that scope. The scope is used only to read and change Google Ads accounts you explicitly authorize. It is not used for any undisclosed purpose.

From those authorized accounts, the application reads:

  • Account and manager-account (MCC) identifiers, names, and relationships
  • Campaigns, ad groups, and ads, including identifiers, names, and status
  • Keywords and match types
  • Budgets, bids, and spend
  • Clicks, impressions, and conversions
  • Ad assets on those campaigns, such as sitelinks and callouts

That data is used only inside Zhijun Ads Manager for advertising management, viewing, and adjustment. It is not sold. It is not used to target advertisements to consumers. It is not used to train artificial-intelligence or machine-learning models. It is not shared with other companies for their own use, and it is not used to resell data or analyze industry data.

The data is stored in the firm's application database and transmitted over HTTPS. It is kept while the Google Ads account stays connected, and for no more than 24 months after that account is disconnected. To request deletion, email marshallmarsxybasi01318@gmail.com. Google API Services User Data Policy

Zhijun Ads Manager complies with the Google API Services User Data Policy, including the Limited Use requirements. The application does not generate AI content, including non-consensual intimate imagery (NCII), and it will not use the Google Ads API to create such imagery.
